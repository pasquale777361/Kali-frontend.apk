This introduces a new Android application 
that serves as a graphical user interface (GUI) for 
a Kali Linux server. The application allows users to 
connect to a server via SSH, execute predefined Kali 
tools, and view the output in real-time.

Key features include:
- SSH connection management with JSch.
- A RecyclerView to display a list of available tools.
- A dialog to prompt for user arguments when required by a tool.
- Real-time output streaming from the server.
- A responsive UI that reflects the current connection status.
